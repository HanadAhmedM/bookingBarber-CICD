# Barberbookning


The application will consist of:

* Java Spring Boot REST API
* HTML, CSS and JavaScript frontend
* PostgreSQL database
* Automated tests
* GitHub Actions CI/CD
* Deployment to Render

## Project status

🚧 Project is currently under development.

## Planned features

* View barbershop services
* View barbers
* Create appointments
* View appointments
* Cancel appointments

## Technologies

### Backend

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL

### Frontend

* HTML

* JavaScript
